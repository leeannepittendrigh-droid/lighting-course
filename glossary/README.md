# Course Glossary

Every term defined across Modules 1, 2, 2B, and 3 — in one searchable place. Type below to filter by term or definition; the list works the same way as the glossary tables inside each module.

## Glossary

| Term | Definition |
|---|---|
| 0–10V Dimming | Analog dimming protocol, most common for commercial |
| AC (Alternating Current) | Power from wall outlets, alternates direction |
| Area Light | Parking lot fixture |
| ASHRAE 90.1 | Energy standard for commercial buildings |
| BACnet | Integration protocol connecting lighting with HVAC/security systems |
| Beam Angle | Cone angle where light drops to 50% of peak intensity |
| Bluetooth Mesh | Wireless fixture control via a mesh network of fixtures |
| Candela (cd) | Light intensity in a specific direction |
| CCT (Correlated Color Temperature) | Color appearance of white light, measured in Kelvin |
| Constant Current Driver | Maintains a fixed current output; most common in complete fixtures |
| Constant Voltage Driver | Maintains a fixed voltage; used for LED tape/strips |
| CRI (Color Rendering Index) | Accuracy of color appearance (0–100 scale) |
| DALI | Digital dimming protocol with individual fixture addressability |
| DC (Direct Current) | Power that flows in one direction — what LEDs use |
| Distribution Type | IES classification for outdoor light patterns (Type I–V) |
| DLC (DesignLights Consortium) | LED product quality verification for utility rebates |
| DLC Premium | Higher efficiency tier, qualifies for maximum rebates |
| DMX512 | Digital protocol for entertainment/color-changing lighting |
| Driver | Converts AC to DC and regulates power for LEDs |
| Dual-Technology Sensor | Combines PIR + Ultrasonic for reliability |
| Efficacy (lm/W) | Efficiency measurement (lumens per watt) |
| Emergency Light | Battery-backup lighting for power outages |
| ETL (Intertek) | Safety testing organization, equivalent to UL |
| Exit Sign | Code-required signage for emergency egress |
| Field Angle | Cone angle where light drops to 10% of peak intensity |
| Foot-candle (fc) | Light level on a surface |
| Garage/Canopy Light | Surface-mounted fixture for covered or garage areas |
| High Bay | Fixture for high-ceiling applications (15+ feet) |
| IC-Rated | Fixture can be in direct contact with insulation |
| IECC (International Energy Conservation Code) | Model energy code |
| IES (Illuminating Engineering Society) | Technical authority that publishes lighting standards |
| IES File | Standardized photometric data file (.ies extension) |
| IK Rating | Impact Protection — mechanical impact resistance |
| IP Rating | Ingress Protection — dust and water resistance |
| LED | Light Emitting Diode — solid-state lighting technology |
| LPD (Lighting Power Density) | Watts per square foot (W/sq ft) |
| Lumen (lm) | Total light output from a source |
| Lux | Metric equivalent of foot-candle (1 fc ≈ 10.76 lux) |
| Multi-Level Switching | Ability to reduce lighting power by at least 50% |
| NEC (National Electrical Code) | NFPA 70 — sets electrical safety standards |
| NFPA 101 (Life Safety Code) | Building fire safety and egress requirements |
| NRTL (Nationally Recognized Testing Laboratory) | Organization authorized to test for safety |
| Occupancy Sensor | Detects presence and controls lighting automatically |
| PIR | Passive Infrared sensor (detects heat/movement) |
| PoE (Power over Ethernet) | Delivers power and data through Ethernet cables |
| Polar Curve | Graph showing light distribution by angle |
| Power (W) | Work being done, measured in watts (Volts × Amps) |
| Power Factor (PF) | Ratio of useful power to total power (want ≥ 0.90) |
| Spacing Criteria (SC) | Maximum spacing-to-mounting-height ratio |
| Task Tuning | Reducing light to appropriate levels within the IES range |
| Title 24 | California energy code (most stringent in the U.S.) |
| Total Harmonic Distortion (THD) | Measure of power quality (want < 20%) |
| Troffer | Recessed fixture that fits in a ceiling grid |
| TRIAC Dimming | Phase-cut dimming for residential applications |
| UL (Underwriters Laboratories) | Safety testing and certification organization |
| Ultrasonic | Sensor using sound waves to detect movement |
| Vacancy Sensor / Mode | Manual-on, auto-off control — prevents nuisance activation |
| Voltage (V) | Electrical pressure that pushes current through wires |
| Wall Pack | Wall-mounted outdoor fixture |
| Watt (W) | Electrical power consumption |
| Zigbee | Low-power wireless protocol for building automation |
